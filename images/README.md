# Main paper figures

These scripts generate the result panels in Figures 2 and 3 from the saved descriptive models. They do not refit the models. Figure 1 is the workflow diagram and is not generated by these scripts.

## Figures

| Panel | Script | PDF output |
| --- | --- | --- |
| Figure 2A — GSE68310 scores | [07_gse68310_panels_AB_paper.R](07_gse68310_panels_AB_paper.R) | `GSE68310_Scores_Paper.pdf` |
| Figure 2B — GSE68310 temporal M2 | Same script | `GSE68310_Temporal_VIP_Paper.pdf` |
| Figure 2C — Interferon and cell-cycle M2 | [04_hallmark_IFN_cellcycle_M2.R](../supplementary/biological_interpretation/04_hallmark_IFN_cellcycle_M2.R) | `M2_IFN_vs_cellcycle.pdf` |
| Figure 3A — GSE182616 scores | [08_gse182616_panels_AB_paper.R](08_gse182616_panels_AB_paper.R) | `GSE182616_Scores_Paper.pdf` |
| Figure 3B — GSE182616 temporal M2 | Same script | `GSE182616_Temporal_VIP_Paper.pdf` |

## Inputs

Run the four main analysis scripts first. Figures 2A/B and 3A/B use `descriptive_models.rds` and `selected_probes.csv` from the saved analysis run. They also require a local TensorPLS checkout, `pkgload` and `ggplot2`.

Figure 2C uses the probe mapping and Hallmark enrichment results from [`supplementary/biological_interpretation/`](../supplementary/biological_interpretation/). It shows M2 from the **all-feature model**, whereas panels 2B and 3B use the **selected-feature model**.

## Reproduce the figures

From the root of the paper repository, set your own paths:

`MAPPING` is the output directory of `01_probe_to_gene.R`; `ENRICH` is the output directory of `02_enrichment.R`. Both are created by the biological interpretation workflow.

```bash
PKG="/path/to/TensorPLS"
RUN="/path/to/analysis_run"
MAPPING="/path/to/mapping_results"
ENRICH="/path/to/enrichment_results"
FIGURES="/path/to/new_figures"

mkdir -p "$FIGURES"

Rscript --vanilla images/07_gse68310_panels_AB_paper.R \
  "$PKG" "$RUN" "$FIGURES/figure2_AB"

Rscript --vanilla supplementary/biological_interpretation/04_hallmark_IFN_cellcycle_M2.R \
  "$MAPPING" "$ENRICH" "$FIGURES/figure2_C"

Rscript --vanilla images/08_gse182616_panels_AB_paper.R \
  "$PKG" "$RUN" "$FIGURES/figure3_AB"
```

Use a new output location for each run. The scripts save the PDFs and supporting CSVs in the three figure directories. Figure 2C also saves a PNG and the probe-group tables.
